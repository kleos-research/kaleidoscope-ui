Cache keys use the lockfile hash, not the branch name
correction written today·applies to every branch
A branch-keyed cache meant every new branch started cold, and two branches with identical dependencies never shared a hit.
Keying on the lockfile hash makes the cache a function of what is actually installed, so a branch that changes no dependencies inherits every entry.
